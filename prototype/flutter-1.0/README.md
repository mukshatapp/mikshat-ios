# مكشات 1.0 — نموذج Flutter مع محرك Organic Maps

مشروع تجريبي مستقل للمقارنة بإصدار مكشات4.6. لا يُعدّل مشروع4.6 أو بياناته، ويستخدم حزمة تطبيق منفصلة حتى يمكن تثبيت النسختين معًا.

الاختيار المعتمد: واجهة Flutter مشتركة، ومحرك Organic Maps، وملفا MWM الحاليان لشمال السعودية وجنوبها. النسخة1.0 تستهدف إثبات الخريطة العربية والبحث والملاحة محليًا، وتسجيل الحركة مع قفل الشاشة. لا تشمل هذه المرحلة النشر على المتاجر أو دمج المشتريات أو اعتماد Android Auto/CarPlay.

مرجع المحرك: `2026.09.29-32-android`. مرجع السلوك والهوية: مكشات4.6، وخط Zain Bold، والأخضر `#164E3F`، ولون النفود `#EBA426`.

تُسجّل نتائج التحقق الفعلية لكل منصة على حدة. بيئة التطوير الحالية Linux؛ بناء iOS والتحقق من سلوك الخلفية على iPhone يحتاج macOS/Xcode وجهازًا فعليًا. تجهيز كود iOS لا يمثل نجاح اختبار تشغيله.

الخرائط وبيانات Organic Maps لها ترخيص مستقل عن الكود. تبقى موافقة الاستخدام بعلامة مكشات مطلوبة قبل التوزيع العام. يظهر الإسناد إلى Organic Maps وOpenStreetMap في الخريطة وصفحة المعلومات.

## المقارنة المستهدفة

| الوظيفة | نتيجة النموذج المطلوبة |
|---|---|
| الخريطة | قراءة ملفات MWM الحالية وعرض العربية والخط والألوان |
| البحث | نتائج حقيقية من فهرس المحرك المحلي دون طلب بحث شبكي |
| الملاحة | حساب مسار سيارة وخط مباشر محليًا مع عرض المسافة والتقدم |
| التسجيل | تخزين نقاط الحركة وحفظها واستعادتها مع اختبار قفل الشاشة |
| البيانات | فصل كامل عن حزمة وملفات مكشات4.6 |

لا تُستخدم نتائج أو إحداثيات وهمية بدل محرك الخرائط. أي تغذية GPS محاكاة تكون ضمن أدوات الاختبار فقط وتُميّز في التقرير.
