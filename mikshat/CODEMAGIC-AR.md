# بدء بناء مكشات باستخدام Codemagic

هذا الإعداد يختبر بناء مصدر المستودع الحالي على محاكي iOS. لا يرفع أي نسخة إلى Apple ولا ينتج IPA قابلاً للتثبيت على هاتف. تعديلات مكشات المحلية الأولية ليست مضمّنة في هذا الفرع.

1. سجّل الدخول إلى https://codemagic.io باستخدام GitHub.
2. اختر Add application واسمح للخدمة بالوصول إلى mukshatapp/mikshat-ios.
3. اختر إعداد المشروع بواسطة codemagic.yaml.
4. اختر الفرع setup/codemagic-ios ثم workflow: mikshat-ios-simulator.
5. ابدأ البناء يدويًا. قد تُحتسب دقائق macOS ضمن رصيد حسابك؛ راجع خطة الحساب قبل البدء.
6. بعد اكتماله، احتفظ برابط البناء وسجل xcodebuild.log. الحزمة الناتجة للمحاكي فقط.

لا تحتاج هذه المرحلة مفاتيح Apple. إصدار Xcode هو latest المتاح بالخدمة؛ المصدر يستخدم واجهات حديثة، ولذلك قد يحتاج إلى إصدار أحدث إذا كان latest في Codemagic أقدم من المصدر.

## TestFlight بعد نجاح البناء الأول

- أكمل نقل واجهات مكشات وتعديلاته إلى المستودع واختبارها.
- سجّل معرّف التطبيق ومعرّف الودجت في حساب Apple وحدّد الاستحقاقات المطلوبة. المصدر الحالي يحتفظ بمعرّفات Organic Maps؛ لا تستخدمها لتوقيع تطبيقك.
- أنشئ سجل التطبيق في App Store Connect.
- من تكاملات Codemagic أضف App Store Connect API key بالصلاحيات المناسبة داخل الخدمة. ملف p8 سري؛ لا ترفعه إلى GitHub أو المحادثة.
- اضبط توقيع التطبيق والودجت وملفات provisioning وiCloud/CarPlay/الروابط المرتبطة لتخص حسابك.
- أضف workflow منفصلًا للتوقيع والأرشفة والرفع إلى TestFlight بعد اكتمال إعداد الحساب والمعرّفات. الإعداد الحالي لا ينشر تلقائيًا ولا يملك بيانات حساب Apple.

التحقق المحلي: صحة YAML وبنية الإعداد فقط. لم يُنفذ البناء على Codemagic بعد.
